Read the result of a paid call by its `paymentId`. Use it when [`pay_service`](/mcp/catalog-mcp/pay-service) answered `{ "status": "pending" }`, or to recover a response you lost. Reading charges nothing. Needs a credential.

**Auth:** key / grant · **Charges:** nothing

## Arguments

| Argument | Required | Type | Description |
| --- | --- | --- | --- |
| `paymentId` | yes | string (uuid) | The `paymentId` a `pay_service` result returned. |
| `inline` | no | boolean | Return the body in the result even when it is binary or larger than the inline limit (as base64 for binary). It can be very large and fill your context: set it only when you cannot fetch the body by `contentUrl` or `resourceUri`. |

## Returns

A `state` and, when ready, the service's response:

```json
{
  "state": "Ready",
  "status": 200,
  "bodyEncoding": "json",
  "body": { "…": "the vendor's response" }
}
```

- `state: "Pending"` — still running; call again in a few seconds. **Don't** call `pay_service` again — it returns the same `pending`.
- `state: "Ready"` — `status` is the service's HTTP status, `body` its response. `bodyEncoding` is `json`, `text`, or `base64`.
- `state: "Ready"` with **`bodyOmitted`** in place of `body` and `bodyEncoding` — the body is binary, or larger than the inline limit (32 KiB by default) as JSON. It is not empty: `bodyOmitted` gives its `contentType`, `sizeBytes`, a `contentUrl` to download and a `resourceUri` to read, and a `resource_link` block follows the JSON; see [When the body is not inlined](/mcp/catalog-mcp/pay-service#when-the-body-is-not-inlined). Pass `inline: true` to get it in the result anyway.
- `state: "Failed"` — the call ended without a response; `failureReason` says why.
- `{ "status": "not_available" }` — nothing to return. Results are kept for **24 hours**, for the account that paid.

## Try it

**Ask your assistant:**

> Get the result of payment `b1f9c2e4-…` (use a `paymentId` from a `pay_service` result).

**Call it directly** (charges nothing):

```bash
curl -X POST https://mcp.live.nevermined.app/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Authorization: Bearer $NVM_API_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_payment_result","arguments":{"paymentId":"b1f9c2e4-0000-0000-0000-000000000000"}}}'
```
