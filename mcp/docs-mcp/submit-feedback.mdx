Report a problem with the documentation site so the docs team can fix it. Use it when a page is incorrect, outdated, confusing, incomplete, or has a broken example. This is for feedback about the **documentation content itself** — not product support requests, and not feedback about the tool or assistant. See the [Docs MCP overview](/mcp/docs-mcp/overview) for how to connect.

**Charges:** nothing.

## Arguments

| Argument | Required | Type | Description |
| --- | --- | --- | --- |
| `path` | yes | string | The URL path of the page the feedback is about (the page you were reading, **without** the `.mdx` extension). |
| `feedback` | yes | string | A clear description of the issue or suggestion — what is incorrect, outdated, missing, or confusing. |

## Returns

A confirmation that the feedback was recorded for the docs team.

## Try it

**Ask your assistant:**

> Report that the `pay_service` page example is missing the required path for multi-endpoint services.

**Call it directly** (the docs server replies over SSE — `event: message` / `data: …`):

```bash
curl -X POST https://nevermined.ai/docs/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"submit_feedback","arguments":{"path":"/mcp/catalog-mcp/pay-service","feedback":"The pay_service example is missing the required path for multi-endpoint services."}}}'
```
