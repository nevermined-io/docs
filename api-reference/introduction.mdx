To interact with Nevermined programmatically, you need a **Nevermined API Key**. This key is required for both:

- **Payment Libraries** (TypeScript SDK and Python SDK)
- **REST API** (direct HTTP calls)

## Get Your API Key

Open [nevermined.app](https://nevermined.app), sign in, then go to **Settings > Global NVM API Keys** and click **+ New API Key**. Copy the key and set it as an environment variable:

```bash
export NVM_API_KEY="sandbox:your-api-key-here"
```

<Warning>
  Keep your API key secure. Do not commit it to version control or share it
  publicly.
</Warning>

## Choose Your Environment

Nevermined offers two environments:

| Environment | Purpose                 | Network      |
| ----------- | ----------------------- | ------------ |
| **Sandbox** | Testing and development | Base Sepolia |
| **Live**    | Production              | Base Mainnet |

<Tabs>
  <Tab title="TypeScript SDK">
    ```typescript
    import { Payments } from '@nevermined-io/payments'

    const payments = Payments.getInstance({
      nvmApiKey: process.env.NVM_API_KEY,
      environment: 'sandbox' // or 'live'
    })
    ```

  </Tab>
  <Tab title="Python SDK">
    ```python
    from payments_py import Payments, PaymentOptions

    payments = Payments.get_instance(
        PaymentOptions(
            nvm_api_key=os.environ['NVM_API_KEY'],
            environment='sandbox'  # or 'live'
        )
    )
    ```

  </Tab>
  <Tab title="REST API">
    | Environment | Base URL |
    |-------------|----------|
    | **Sandbox** | `https://api.sandbox.nevermined.app/api/v1` |
    | **Live** | `https://api.live.nevermined.app/api/v1` |

    ```bash
    curl -X GET "https://api.sandbox.nevermined.app/api/v1/protocol/agents" \
      -H "Authorization: Bearer $NVM_API_KEY"
    ```

  </Tab>
</Tabs>

## API Versioning

Every request resolves to a pinned API version (the platform release `MAJOR.MINOR`), so your integration keeps working across releases. The pin comes from your API key (editable in the dashboard) or, per request, from the optional `Nevermined-Version` header:

```bash
curl -X GET "https://api.sandbox.nevermined.app/api/v1/protocol/agents" \
  -H "Authorization: Bearer $NVM_API_KEY" \
  -H "Nevermined-Version: 1.0"
```

See [API Versioning](/development-guide/api-versioning) for the resolution rules and compatibility guarantees, and the [API Changelog](/development-guide/api-changelog) for what changed in each version.

## Authentication

Every request is authenticated with a single bearer header — `Authorization: Bearer <nevermined-api-key>`. The key above is all most integrations need. For the full picture — the on-chain identity model, obtaining a key **with or without a browser** (the OAuth 2.1 Authorization Code and RFC 8628 device flows), standards-based discovery, and how to read a `401` — see the [**Authentication & Identity** guide](/integrate/authentication/overview).

## Error model

Errors return a typed envelope — a `BCK.<MODULE>.<NNNN>` code, a `message`, often a `hint`, a `category`, and an `x-correlation-id` header. Branch on the `code`/`category`, not the prose. See the [API error model](/development-guide/api-errors/overview) for the shape and the [API error codes](/development-guide/api-errors/codes) for the full catalog.
