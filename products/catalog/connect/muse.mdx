Muse will be able to browse the [Nevermined Catalog](/products/catalog/overview) and pay for services with a plain Nevermined API key. This page covers the account and funding you can set up now and the directory connector that's on the way; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Muse connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Muse.
</Note>

<Warning>
**The connector is on the way.** The Muse Connector Platform ([platform.muse.ai](https://platform.muse.ai)) is a **submission-and-review** directory — a connector is published by its developer and, once approved, becomes discoverable in the Muse agent and under **Settings → Connectors**. There is no self-serve "add a custom MCP server" flow for end users, so you can't add the Catalog yourself yet. Nevermined is submitting the Catalog connector for listing; until it's approved, drive the Catalog from your own code or another host — see [Using the Catalog from a harness](/products/catalog/from-a-harness). {/* TODO (Wave 3, nvm-monorepo#4545): once the Muse connector is approved, document the "find Nevermined in Settings → Connectors → paste your key" steps here. */}
</Warning>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription) — the free credits a new account gets when it signs up with a verified email, top-up packs, or a Nevermined Subscription's monthly allowance — or from a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Muse at **live**.
</Note>

## Add the Catalog to Muse

The Catalog will appear in Muse's **Settings → Connectors** once Nevermined's connector is approved on the Muse Connector Platform (in progress — see the warning above). When it's listed, this section becomes: find Nevermined in the connectors directory and paste your Nevermined API key.

In the meantime, your Nevermined account and funding are already usable from any host that accepts an API-key header, or from your own code — see [Using the Catalog from a harness](/products/catalog/from-a-harness).

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Muse. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Once the connector is listed, ask for something only live data can answer, and name the connector so Muse reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Ask Muse to *"list the Nevermined catalog categories"* — a free tool call, no payment.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined connector and show me the response."* The paid call draws on your Nevermined credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If Muse answers without paying, it answered from its own knowledge — name the connector and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut Muse off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (Muse side).** Once the connector is listed, disconnect it from Muse's **Settings → Connectors**.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
