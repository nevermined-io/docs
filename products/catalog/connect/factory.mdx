Factory Droid can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as it works, without you handing over an API key. You add one server, approve a single spending cap, and Droid does the rest. This is the per-host walkthrough; for the concept and the other assistants, see [Using the Catalog from your web assistant](/products/catalog/from-your-web-assistant).

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app). You never share an API key with Droid — the consent cap *is* the credential.
  </Step>
  <Step title="A funded wallet">
    A paid call draws on a **spending cap** you approve during connect — a [commerce grant](/mcp/catalog-mcp/overview#auth-&-transport): a capped, revocable budget funded from your own wallet, not a key. Fund that wallet first with the asset the service settles in — see [Fund your wallet](/products/catalog/router/quickstart#3-fund-your-wallet). You approve the cap itself in [Approve the spending cap](#approve-the-spending-cap).
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Droid at **live**.
</Note>

## Add the Catalog to Factory Droid

<Steps>
  <Step title="Add the MCP server">
    Add the Nevermined Catalog as a remote HTTP MCP server with `droid mcp add`, pointing at the environment you want:

    ```bash
    droid mcp add nevermined https://mcp.api.sandbox.nevermined.app/mcp --type http   # live: https://mcp.api.live.nevermined.app/mcp
    ```

    The entry lands in your user config at `~/.factory/mcp.json` (a project-scoped `.factory/mcp.json` works too — don't commit secrets there). Pass no `--header` and no `--no-oauth`: Droid identifies itself to Nevermined with its own client metadata document and runs the OAuth (PKCE) flow, so there is nothing to register and no key to paste.
    {/* Uses the mcp.api.<env> host (challenges on connect), not the quickstart mcp.<env> host: Droid is an explicit-auth host — it marks a server "needs authentication" and offers /mcp → Authenticate only when connecting gets a 401 challenge. mcp.<env> serves initialize/tools-list unchallenged (mcp/catalog-mcp/overview.mdx:180), so Droid would list the server as connected and never prompt; overview.mdx:355 routes explicit-auth hosts to the connect-challenge host. */}
  </Step>
  <Step title="Sign in">
    `droid mcp list` shows the server as **needs authentication** until you sign in. Run `/mcp`, select the Nevermined server and choose **Authenticate** — Droid opens Nevermined's consent page in your browser. See [Approve the spending cap](#approve-the-spending-cap).
  </Step>
</Steps>

## Approve the spending cap

Factory Droid opens Nevermined's consent page when you authenticate the server — the `/mcp` → **Authenticate** step above. It is the one place a human is required.

<Steps>
  <Step title="Check who and where">
    The page shows the **Sandbox / Live** badge and **who is asking**. On **live**, the cap is real money.
  </Step>
  <Step title="Set the cap and validity">
    Set the **spending cap** (USDC or EURC) and how long the grant is **valid for**, then **Grant access**.
  </Step>
</Steps>

That approval is a **commerce grant**: it spends only from the budget you just approved, only through the [Router](/products/catalog/router/overview), and you can revoke it any time. Nevermined's routing fee comes out of the same cap, and the grant can also read your payment history and wallet balance — [the cap bounds what it can spend, not what it can see](/mcp/catalog-mcp/overview#what-the-consent-page-asks).

## Make your first paid call

Ask for something only live data can answer, and name the connector so Droid reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Ask *"list the Nevermined catalog categories"* — a free tool call that doesn't draw on your cap.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined connector and show me the response."* The paid call draws on the cap you approved and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If Droid answers without paying, it answered from its own knowledge — name the connector and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect

- **Revoke the budget (Nevermined side).** Open [Connections](https://nevermined.app/connections) and disconnect Factory Droid. The credential stops working on its next call; discovery still works.
- **Remove the connector (Factory Droid side).** In `/mcp`, choose **Clear auth** to drop the stored OAuth credentials, then **Remove** to delete the server — or delete its entry from `~/.factory/mcp.json`.

To spend again — after you disconnect, or after a cap is used up — re-run the connect step and approve a **new** cap. A budget is never widened or extended in place.
