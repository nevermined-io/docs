Zapier can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as a Zap runs. You add the MCP Client, paste your Nevermined API key, and Zapier does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Zapier connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Zapier.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from one of two budgets you set up once: a [Nevermined Subscription](/products/catalog/router/subscription) whose monthly credits a plain key can spend, or a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Zapier at **live**.
</Note>

## Add the Catalog to Zapier

<Steps>
  <Step title="Add the MCP Client">
    In a Zap, add the **MCP Client** (beta) and choose **Connect an Account**.
  </Step>
  <Step title="Point it at the server">
    Set **Server URL** to the Catalog MCP URL for your environment and **Transport** to **Streamable HTTP**:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |
  </Step>
  <Step title="Set the Bearer token">
    Leave **OAuth** set to **No**, and paste your Nevermined API key into the **Bearer Token** field.
  </Step>
</Steps>

<Note>
Zapier's **MCP Client is in beta** and its fields may change.
</Note>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Zapier. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Give a Zap a task that needs a live, paid service, so the MCP Client reaches for the Catalog tools rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Have the Zap call a free discovery tool first — *list the Nevermined catalog categories*, or *search the catalog for a weather service*. Discovery needs no payment.
  </Step>
  <Step title="Let it buy">
    Then have it pay a service by slug — *buy the service `<slug>` and return the response*. The paid call draws on your subscription credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If the Zap answers without paying, it answered from its own knowledge — have it call a discovery tool first and ask for something only live data can answer. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut Zapier off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (Zapier side).** Remove the Nevermined MCP Client connection from your connected accounts.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
