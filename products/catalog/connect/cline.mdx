Cline can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as it works. You add one remote MCP server, paste your Nevermined API key, and Cline does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Cline connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Cline.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription) — the free credits a new account gets when it signs up with a verified email, top-up packs, or a Nevermined Subscription's monthly allowance — or from a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Cline at **live**.
</Note>

## Add the Catalog to Cline

<Steps>
  <Step title="Open the Remote Servers tab">
    Click the **MCP Servers** icon in Cline's toolbar, open the **Remote Servers** tab, and give the server a name (e.g. `nevermined-catalog`).
  </Step>
  <Step title="Point it at the server">
    Paste the URL for the environment you want and set **Transport Type** to **Streamable HTTP**:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |
  </Step>
  <Step title="Add your API key as a header">
    Cline stores servers in `cline_mcp_settings.json`. Add your Nevermined API key as an `Authorization` header — edit it in the **Configure MCP Servers** JSON:

    ```json
    {
      "mcpServers": {
        "nevermined-catalog": {
          "type": "streamableHttp",
          "url": "https://mcp.live.nevermined.app/mcp",
          "headers": { "Authorization": "Bearer <your Nevermined API key>" }
        }
      }
    }
    ```
  </Step>
</Steps>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Paste it in place of `<your Nevermined API key>` and keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Cline. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Ask for something only live data can answer, and name the server so Cline reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    In Cline's chat, ask *"list the Nevermined catalog categories"* — a free tool call, no payment.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined server and show me the response."* The paid call draws on your Nevermined credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If Cline answers without paying, it answered from its own knowledge — name the server and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut Cline off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (Cline side).** In the **MCP Servers** panel delete the Nevermined server, or remove its block from `cline_mcp_settings.json`.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
