H Company's Runner H can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as an agent works, unattended and under a budget you set. You attach the Catalog as a native MCP server on the agent, pass your Nevermined API key, and the agent discovers and pays for what a task needs. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
H Company connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential: it spends whatever its Nevermined account funds, so you set the budget on your account, not in H Company.
</Note>

The point is how little there is to wire up. You do not integrate a recalls provider and a model vendor, each with its own account, key, and invoice. You describe the result you want, an [Outcome](/products/catalog/build-outcomes), and the Catalog composes the services at run time and pays each one per call. Given a Peloton Tread+, the agent found the real CPSC recall of 2021, wrote a HIGH-risk brief from it, and paid for exactly the two calls it needed.

## What one run looks like

On a run the agent calls the Catalog more than once. For each part of the brief it searches for a service that fits, pays for that one call, and moves on, all against the same budget.

| Step | Service it paid | What came back | Cost |
| --- | --- | --- | --- |
| 1 | `recallradar` (recall lookup) | The real **CPSC recall of 2021-05-05**: the Tread+ entrapment hazard, the remedy, and the cpsc.gov source | 150 credits, settled, upstream 200 |
| 2 | `perplexity` (`sonar`) | The risk brief written from that record plus live sources, with 10 citations | 15 credits, settled, upstream 200 |

The agent then emitted a sourced **HIGH-risk** brief: the active CPSC recall, the hazard, the remedy, a recommended action, and the source link. About **165 credits** in total, all from the account's **subscription credits**, with no stablecoin spend. It paid for the two calls it needed and nothing else, and it could not exceed the budget it was given. The Catalog tool calls in this run were resolved by the integration's own backend (see the note under [Add the Catalog to H Company](#add-the-catalog-to-h-company)).

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app (**Settings → Global NVM API Keys**) for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow cannot pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription): the free credits a new account gets when it signs up with a verified email, top-up packs, or a Nevermined Subscription's monthly allowance. It can also spend from a capped, revocable **delegation** funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
  <Step title="An H Company agent">
    Access to H Company's Agents API (`https://agp.eu.hcompany.ai/api`) with your H Company API key, so you can define an agent and run a session.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point H Company at **live**. The Catalog is **Live-only for payment**: sandbox discovers services but cannot settle a real one, so run the money path on **live** with a small cap.
</Note>

## Add the Catalog to H Company

Runner H attaches a remote MCP server through a native `mcp` environment on the agent. Give the agent an environment of `kind: "mcp"` whose `servers` list points at the Catalog MCP for your environment, and put your Nevermined API key in the `Authorization` header:

```jsonc
{
  "kind": "mcp",
  "id": "mcp",
  "servers": [
    {
      "name": "nevermined",
      "transport": "streamable_http",
      "url": "https://mcp.live.nevermined.app/mcp",
      "headers": { "Authorization": "Bearer <your Nevermined API key>" }
    }
  ]
}
```

| Environment | Server URL |
| --- | --- |
| **Sandbox** (the right place for a first run) | `https://mcp.sandbox.nevermined.app/mcp` |
| **Live** (real merchants, real money) | `https://mcp.live.nevermined.app/mcp` |

- **Transport must be `streamable_http`.** The Catalog MCP speaks Streamable HTTP only, so `sse` and `stdio` will not reach it.
- **The header is the whole auth.** With `headers: {}` the agent still gets the free discovery tools; add the `Authorization: Bearer` header to call the paid tools. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

Define the agent once (`POST /v2/agents`) and run sessions against it by name, or pass the agent inline per session. Once the environment is attached, the whole Catalog is available to the agent as tools it can call: **search** for a service, get a **quote**, **pay**, and check what is left of the **budget**. Discovery tools are free; the rest draw on your budget. See the [Catalog MCP page](/products/catalog/mcp) for the setup, and the [full Catalog MCP reference](/mcp/catalog-mcp/overview) for every tool, its arguments, and the refusal codes.

<Warning>
As of October 2026, a **delivered paid call does not reliably complete through H Company's native `mcp` connector**. The connection, the key, discovery, and the payment rails all work (a real on-ledger payment fires), but H Company's agent mis-forwards the structured `pay_service` arguments, so the merchant call errors even though the identical call succeeds when sent straight to the Catalog MCP. This is an H Company-side fix, not a Nevermined one.

Until it lands, resolve each paid Catalog tool call in **your own backend** and post the result back to the session. That path completes end to end today, and it is what the demo above used. The plain-key tool surface is in [Using the Catalog from a harness](/products/catalog/from-a-harness). Native discovery is unaffected.
</Warning>

## The budget is the guardrail

An agent runs with no human watching each call, so the budget does the work a person would. The key spends only what its Nevermined account funds, and the cap is enforced on Nevermined's side, not inside H Company.

- **The agent cannot raise it.** Fund a **delegation cap**, or rely on your **subscription credit** balance (165 credits for the recall run above), and every paid call settles against it. A runaway agent physically cannot spend past the cap, and when it is reached, calls stop.
- **You can revoke it any time**, in one action, from [Payment methods](https://nevermined.app/payment-methods). The next call simply fails, and discovery still works.
- **Keep the cap tight.** Treat the H Company secret that stores the key as spending authority, and give each agent only the budget its job needs.

## Make your first paid call

Give the agent a task that needs a live, paid service, so it reaches for the Catalog tools rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Ask the agent to call a free discovery tool first, for example *list the Nevermined catalog categories* or *search the catalog for a recalls service*. Discovery runs natively through the `mcp` environment and needs no payment.
  </Step>
  <Step title="Let it buy">
    Then ask it to pay a service by slug, for example *buy the service `<slug>` and return the response*. The paid call draws on your Nevermined credits or delegation and returns the merchant's response. Until H Company ships the argument-forwarding fix above, route the paid tool call through your own backend so it completes; discovery stays native.
  </Step>
</Steps>

<Tip>
If the agent answers without paying, it answered from its own knowledge. Have it call a discovery tool first and ask for something only live data can answer. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut H Company off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**); every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (H Company side).** Remove the `mcp` environment from the agent, or retire the agent, and clear the stored `Authorization` header.

To spend again, attach a fresh key; if you revoked the delegation, create a new one. See [Using the Catalog from a harness](/products/catalog/from-a-harness).
