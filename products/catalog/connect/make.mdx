Make can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as a scenario runs. You add the MCP Client, paste your Nevermined API key, and Make does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Make connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Make.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription) — the free credits a new account gets when it signs up with a verified email, or a Nevermined Subscription's monthly allowance — or from a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Make at **live**.
</Note>

## Add the Catalog to Make

<Steps>
  <Step title="Add the MCP Client">
    In a Make scenario, add the **MCP Client** app (its **Call a tool** / **Execute an action with AI** modules), and create a connection with **+ New MCP Server**.
  </Step>
  <Step title="Point it at the server">
    Set the server **URL** to the environment you want:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |
  </Step>
  <Step title="Add your API key">
    For a manually-entered server Make shows an **API Key / Access token** field — paste your Nevermined API key there.
  </Step>
</Steps>

<Warning>
**Verify this before relying on it.** Make's own docs don't state that the **API Key / Access token** value is sent as an `Authorization: Bearer` header, and the Catalog MCP accepts only that header. Test on **sandbox** first; if the key is rejected, the Catalog may need to be added to Make's **verified remote MCP servers** list — [reach out](https://nevermined.ai/contact-us) and we'll help. {/* TODO (Wave 3, nvm-monorepo#4545): confirm Make's MCP Client sends Authorization: Bearer, or arrange the verified-server listing; then replace this warning with the confirmed steps. */}
</Warning>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Make. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Give a scenario a task that needs a live, paid service, so the MCP Client reaches for the Catalog tools rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Have the scenario call a free discovery tool first — *list the Nevermined catalog categories*, or *search the catalog for a weather service*. Discovery needs no payment.
  </Step>
  <Step title="Let it buy">
    Then have it pay a service by slug — *buy the service `<slug>` and return the response*. The paid call draws on your Nevermined credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If the scenario answers without paying, it answered from its own knowledge — have it call a discovery tool first and ask for something only live data can answer. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut Make off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (Make side).** Delete the Nevermined MCP Client connection from your scenario and your connections.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
