OpenCode can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as it works, without you handing over an API key. You add one server, approve a single spending cap, and OpenCode does the rest. This is the per-host walkthrough; for the concept and the other assistants, see [Using the Catalog from your web assistant](/products/catalog/from-your-web-assistant).

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app). You never share an API key with OpenCode — the consent cap *is* the credential.
  </Step>
  <Step title="A funded wallet">
    A paid call draws on a **spending cap** you approve during connect — a [commerce grant](/mcp/catalog-mcp/overview#auth-&-transport): a capped, revocable budget funded from your own wallet, not a key. Fund that wallet first with the asset the service settles in — see [Fund your wallet](/products/catalog/router/quickstart#3-fund-your-wallet). You approve the cap itself in [Approve the spending cap](#approve-the-spending-cap).
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point OpenCode at **live**.
</Note>

## Add the Catalog to OpenCode

<Steps>
  <Step title="Add the server to your OpenCode config">
    Add a remote MCP server to your OpenCode config — the global `~/.config/opencode/opencode.json`, or `opencode.json` in a project root — pointing at the environment you want. Set the OAuth **client id** to `opencode` and leave the **secret** out — Nevermined accepts public PKCE clients only, so there is no secret to paste:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "nevermined": {
          "type": "remote",
          "url": "https://mcp.sandbox.nevermined.app/mcp",
          "oauth": {
            "clientId": "opencode"
          }
        }
      }
    }
    ```

    For **live**, use `https://mcp.live.nevermined.app/mcp`. You don't need to set a redirect URI — OpenCode's default loopback callback (`http://127.0.0.1:19876/mcp/oauth/callback`) is already registered for the `opencode` client, and Nevermined matches it on any port.
  </Step>
  <Step title="Sign in">
    Run `opencode mcp auth nevermined`. OpenCode opens Nevermined's consent page in your browser — see [Approve the spending cap](#approve-the-spending-cap).
  </Step>
</Steps>

## Approve the spending cap

OpenCode opens Nevermined's consent page when you run `opencode mcp auth`. It is the one place a human is required.

<Steps>
  <Step title="Check who and where">
    The page shows the **Sandbox / Live** badge and **who is asking**. On **live**, the cap is real money.
  </Step>
  <Step title="Set the cap and validity">
    Set the **spending cap** (USDC or EURC) and how long the grant is **valid for**, then **Grant access**.
  </Step>
</Steps>

That approval is a **commerce grant**: it spends only from the budget you just approved, only through the [Router](/products/catalog/router/overview), and you can revoke it any time. Nevermined's routing fee comes out of the same cap, and the grant can also read your payment history and wallet balance — [the cap bounds what it can spend, not what it can see](/mcp/catalog-mcp/overview#what-the-consent-page-asks).

## Make your first paid call

Ask for something only live data can answer, and name the connector so OpenCode reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Ask *"list the Nevermined catalog categories"* — a free tool call, no sign-in.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined connector and show me the response."* The paid call draws on the cap you approved and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If OpenCode answers without paying, it answered from its own knowledge — name the connector and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect

- **Revoke the budget (Nevermined side).** Open [Connections](https://nevermined.app/connections) and disconnect OpenCode. The credential stops working on its next call; discovery still works.
- **Remove the connector (OpenCode side).** Run `opencode mcp logout nevermined` to clear the stored tokens (OpenCode keeps them in `~/.local/share/opencode/mcp-auth.json`), then remove the `nevermined` entry from the `mcp` block in your `opencode.json`.

To spend again — after you disconnect, or after a cap is used up — re-run the connect step and approve a **new** cap. A budget is never widened or extended in place.
