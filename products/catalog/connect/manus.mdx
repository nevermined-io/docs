Manus can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as it works. You add one custom MCP server, paste your Nevermined API key, and Manus does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Manus connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Manus.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription) — the free credits a new account gets when it signs up with a verified email, top-up packs, or a Nevermined Subscription's monthly allowance — or from a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Manus at **live**.
</Note>

## Add the Catalog to Manus

<Steps>
  <Step title="Open Custom MCP Servers">
    In Manus, go to **Settings → Integrations → Custom MCP Servers** and click **Add Server**.
  </Step>
  <Step title="Point it at the server">
    Give it a **Server name** and set **Server URL** to the HTTPS endpoint for the environment you want:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |
  </Step>
  <Step title="Set the authentication">
    For **Authentication**, choose **Bearer token** (API key) and paste your Nevermined API key.
  </Step>
</Steps>

<Note>
Rehearse on **sandbox** first. The Catalog MCP accepts only the exact header `Authorization: Bearer <key>`; if Manus sends your key in another shape, calls look connected but never pay — if that happens, ask for a free discovery call and confirm a paid one actually charges before trusting it on **live**.
</Note>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Manus. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Ask for something only live data can answer, and name the server so Manus reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Ask Manus to *"list the Nevermined catalog categories"* — a free tool call, no payment.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined server and show me the response."* The paid call draws on your Nevermined credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If Manus answers without paying, it answered from its own knowledge — name the server and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut Manus off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (Manus side).** In **Settings → Integrations → Custom MCP Servers**, open the Nevermined server and remove it.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
