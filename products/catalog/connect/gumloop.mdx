Gumloop can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as a flow runs. You add one MCP connector, paste your Nevermined API key, and Gumloop does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Gumloop connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Gumloop.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription) — the free credits a new account gets when it signs up with a verified email, or a Nevermined Subscription's monthly allowance — or from a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Gumloop at **live**.
</Note>

## Add the Catalog to Gumloop

<Steps>
  <Step title="Open the MCP connector dialog">
    In Gumloop, go to **Settings → Connectors**, click the arrow next to **Add Connector**, and choose **Add MCP Connector**.
  </Step>
  <Step title="Point it at the server (Public URL)">
    Set **Connection type** to **Public URL** and paste the URL for the environment you want:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |
  </Step>
  <Step title="Set the authentication">
    Under **Configure**, set **Authentication** to **Access Token / API Key** and paste your Nevermined API key — Gumloop sends it as `Authorization: Bearer <key>` on every request, which is exactly what the Catalog MCP expects.

    <Warning>
    Use the **Access Token / API Key** field, **not** the *Additional Header* field. Gumloop's docs note that Anthropic models drop custom headers, so an `Authorization` header added through *Additional Header* may not be forwarded — the **Access Token / API Key** field is.
    </Warning>
  </Step>
</Steps>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Gumloop. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Give a flow a task that needs a live, paid service, so the agent reaches for the Catalog tools rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Have the flow call a free discovery tool first — *list the Nevermined catalog categories*, or *search the catalog for a weather service*. Discovery needs no payment.
  </Step>
  <Step title="Let it buy">
    Then have it pay a service by slug — *buy the service `<slug>` and return the response*. The paid call draws on your Nevermined credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If the flow answers without paying, it answered from its own knowledge — have it call a discovery tool first and ask for something only live data can answer. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut Gumloop off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the connector (Gumloop side).** In **Settings → Connectors**, open the Nevermined MCP connector and remove it.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
