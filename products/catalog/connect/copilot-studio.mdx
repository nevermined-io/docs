A Microsoft 365 Copilot agent built in Copilot Studio can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as it works. You add one MCP tool, paste your Nevermined API key, and the agent does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
Copilot Studio connects with a **plain Nevermined API key** in a header, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use — and not a customer Entra OAuth app. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in Copilot Studio.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from your [Nevermined credits](/products/catalog/router/subscription) — the free credits a new account gets when it signs up with a verified email, or a Nevermined Subscription's monthly allowance — or from a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point the agent at **live**.
</Note>

## Add the Catalog to your agent

<Steps>
  <Step title="Add an MCP tool">
    In your Copilot Studio agent, open **Tools → Add a tool → New tool → Model Context Protocol**.
  </Step>
  <Step title="Point it at the server">
    Enter a **Server name** and **Server description**, and set **Server URL** to the environment you want:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |
  </Step>
  <Step title="Authenticate with your key">
    Set **Authentication** to **API key**, choose **Type = Header**, use the header name `Authorization`, and supply `Bearer <your Nevermined API key>` as the value.

    <Note>
    If Copilot Studio adds the `Bearer ` prefix for you, supply just the key — the header that reaches the server must read `Authorization: Bearer <key>`.
    </Note>
  </Step>
</Steps>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in Copilot Studio. Treat it like a password: never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Ask for something only live data can answer, and name the tool so the agent reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    In a test chat, ask the agent to *"list the Nevermined catalog categories"* — a free tool call, no payment.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined tool and show me the response."* The paid call draws on your Nevermined credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If the agent answers without paying, it answered from its own knowledge — name the tool and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut the agent off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (Copilot Studio side).** In the agent's **Tools**, open the Nevermined MCP tool and remove it.

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
