n8n can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as a workflow runs. You add one MCP Client Tool node, paste your Nevermined API key, and n8n does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
n8n connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in n8n.
</Note>

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from one of two budgets you set up once: a [Nevermined Subscription](/products/catalog/router/subscription) whose monthly credits a plain key can spend, or a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point n8n at **live**.
</Note>

## Add the Catalog to n8n

<Steps>
  <Step title="Add an MCP Client Tool node">
    In your workflow, add an **MCP Client Tool** node and connect it to your **AI Agent** node's tool input.
  </Step>
  <Step title="Point it at the server">
    Set the endpoint to the Catalog MCP URL for your environment, and choose **HTTP Streamable** as the transport:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |

    <Note>
    The Catalog MCP speaks **Streamable HTTP** only. If your n8n version offers only an SSE endpoint field, update n8n to a version with the HTTP Streamable transport option.
    </Note>
  </Step>
  <Step title="Set Bearer authentication">
    Set **Authentication** to **Bearer** and paste your Nevermined API key — or use a **Header Auth** credential with name `Authorization` and value `Bearer <your Nevermined API key>`.
  </Step>
</Steps>

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in n8n. Store it in an n8n credential, treat it like a password, and never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## Make your first paid call

Give your agent a task that needs a live, paid service, so it reaches for the Catalog tools rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Have the AI Agent call a free discovery tool first — *list the Nevermined catalog categories*, or *search the catalog for a weather service*. Discovery needs no payment.
  </Step>
  <Step title="Let it buy">
    Then have it pay a service by slug — *buy the service `<slug>` and return the response*. The paid call draws on your subscription credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If the agent answers without paying, it answered from its own knowledge — have it call a discovery tool first and ask for something only live data can answer. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut n8n off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (n8n side).** Delete or disable the **MCP Client Tool** node in your workflow (and remove the stored credential if you no longer need it).

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
