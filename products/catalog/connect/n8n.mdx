n8n can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as a workflow runs — unattended, on a schedule, under a budget you set. You add one MCP Client Tool node, paste your Nevermined API key, and n8n does the rest. This is the per-host walkthrough; for the full tool surface and the safety model, see [Using the Catalog from a harness](/products/catalog/from-a-harness).

<Note>
n8n connects with a **plain Nevermined API key**, not the OAuth "approve a spending cap" flow that some assistants (Claude, ChatGPT) use. The key is your credential — it spends whatever its Nevermined account funds, so you set the budget on your account, not in n8n.
</Note>

## See it in action

To ground the setup, here is a workflow we built and ran on n8n: a weekly **agentic-commerce research agent**. Every Monday it wakes on a schedule, researches the last seven days of agentic commerce, and returns a short brief — delivered to Slack and by email. It discovers and pays for the services it needs on its own, under a **$2 budget** it cannot exceed.

The point is how little there is to wire up. You don't integrate a search provider, a funding-data provider, and three social sources, each with its own account, key, and invoice. You describe the result you want and set a budget — an [Outcome](/products/catalog/build-outcomes) — and the Catalog composes the services at run time and pays each one per call.

<Frame caption="One prompt and a $2 budget go in; the Catalog discovers and chains the services it needs — news and web search, newly launched and funded companies, and social signals across X, LinkedIn and Hacker News — reads the sources, writes the report, and returns one weekly brief. Every call is paid per use against the one budget.">
  <img src="/images/catalog/n8n/catalog-outcome.png" alt="The Outcome composition: a prompt and a $2 budget feed a chain of catalog services grouped by job — news and web search, company and funding data, social signals, and a read-and-write step — producing one weekly report delivered to Slack and email." />
</Frame>

You don't choose the services by name, and which ones a given week uses isn't fixed. The agent discovers what the prompt needs — a web-search service such as [You.com](https://you.com) for the week's news, company- and funding-data services, separate sources for X, LinkedIn and Hacker News, a scraper to read the primary links, and a model to dedupe, rank and write the brief — then pays only for the calls it makes. Discovery is free, so it re-checks what's live on every run rather than hard-coding a list.

All of that reaches n8n through a single node. The finished workflow is **six nodes**: a weekly Schedule Trigger into an AI Agent that has the Nevermined Commerce MCP wired in as its one tool, which then branches to Slack and email. There is no code node and no custom plugin — n8n even runs the model, so there's no model key to add either.

## What one run looks like

On a run the agent calls the Catalog several times, not once. For each part of the brief it searches for a service that fits, reads a quote, pays for that one call, and moves on — all against the same budget.

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app).
  </Step>
  <Step title="A Nevermined API key">
    Create a **plain** API key in the app — **Settings → Global NVM API Keys** — for the environment you want, and send the whole string, prefix included (`sandbox:…` or `live:…`). A key minted by an OAuth flow can't pay through the Router's delegation routes, so use a plain one. See [Get a Nevermined API key](/agents-guide/get-api-key).
  </Step>
  <Step title="A way to pay">
    The key spends from one of two budgets you set up once: a [Nevermined Subscription](/products/catalog/router/subscription) whose monthly credits a plain key can spend, or a spending **delegation** — a capped, revocable budget funded from your own wallet ([Using the Catalog from a harness](/products/catalog/from-a-harness) walks through it). Discovery is free and needs neither.
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point n8n at **live**. The Catalog is **Live-only for payment** — sandbox discovers services but cannot settle a real one, so run the money path on **live** with a small cap.
</Note>

## Add the Catalog to n8n

<Steps>
  <Step title="Add an MCP Client Tool node">
    In your workflow, add an **MCP Client Tool** node and connect it to your **AI Agent** node's tool input.
  </Step>
  <Step title="Point it at the server">
    Set the endpoint to the Catalog MCP URL for your environment, and choose **HTTP Streamable** as the transport:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |

    <Note>
    The Catalog MCP speaks **Streamable HTTP** only. If your n8n version offers only an SSE endpoint field, update n8n to a version with the HTTP Streamable transport option.
    </Note>
  </Step>
  <Step title="Set Bearer authentication">
    Set **Authentication** to **Bearer** and paste your Nevermined API key — or use a **Header Auth** credential with name `Authorization` and value `Bearer <your Nevermined API key>`.
  </Step>
</Steps>

<Frame caption="The n8n-side configuration: the MCP Client Tool node points at the Commerce MCP endpoint with a single Authorization: Bearer header — the Nevermined API key, kept in an n8n credential and never written into the workflow. From there the whole Catalog is exposed to the agent as tools: search, quote, pay, and check the budget.">
  <img src="/images/catalog/n8n/n8n-config.png" alt="n8n configuration panels: the MCP Client Tool node set to the Commerce MCP endpoint with Bearer header auth (key masked), the catalog exposed as tools, and the schedule, AI Agent, Slack and Gmail nodes each with their own credential." />

Once the node is pointed at the server, the whole Catalog is available to the agent as tools it can call: **search** for a service, get a **quote**, **pay**, and check what's left of the **budget**. Discovery tools are free; the rest draw on your budget. See the [Catalog MCP page](/products/catalog/mcp) for the setup, and the [full Catalog MCP reference](/mcp/catalog-mcp/overview) for every tool, its arguments, and the refusal codes.

## Your Nevermined API key

That key is your credential — there is no separate consent screen to approve. Keep the prefix: a `live:` key for `mcp.live`, a `sandbox:` key for `mcp.sandbox`.

The key spends whatever its account funds — your [Subscription](/products/catalog/router/subscription) credits, or a [spending delegation](/products/catalog/from-a-harness) funded from your wallet — so the budget and the audit trail live on your Nevermined account, not in n8n. Store it in an n8n credential, treat it like a password, and never commit it or paste it into a shared chat. Every way to mint one: [Get a Nevermined API key](/agents-guide/get-api-key).

## The budget is the guardrail

A scheduled workflow runs with no human watching each call, so the budget does the work a person would. Set a **delegation cap** to the most you want the workflow to spend — $2 for the research agent above — and fund it once; every paid call settles against that cap.

- **The agent cannot raise it.** The cap is enforced on Nevermined's side, not in n8n, so a runaway workflow physically cannot spend past it. When the budget is reached, calls stop.
- **You can revoke it any time**, in one action, from [Payment methods](https://nevermined.app/payment-methods) — the next call simply fails, and discovery still works.
- **Keep the cap tight**, and set a per-run budget if you want each run isolated. Treat the n8n credential that holds the key as spending authority.

## Make your first paid call

Give your agent a task that needs a live, paid service, so it reaches for the Catalog tools rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Have the AI Agent call a free discovery tool first — *list the Nevermined catalog categories*, or *search the catalog for a weather service*. Discovery needs no payment.
  </Step>
  <Step title="Let it buy">
    Then have it pay a service by slug — *buy the service `<slug>` and return the response*. The paid call draws on your subscription credits or delegation and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If the agent answers without paying, it answered from its own knowledge — have it call a discovery tool first and ask for something only live data can answer. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect or rotate the key

- **Stop the credential (Nevermined side).** The key *is* the credential, so to cut n8n off, **rotate or delete the key** in the app (**Settings → Global NVM API Keys**) — every call with the old key then fails. To cap spending without revoking the key, revoke the delegation it spends from in [Payment methods](https://nevermined.app/payment-methods); discovery still works.
- **Remove the server (n8n side).** Delete or disable the **MCP Client Tool** node in your workflow (and remove the stored credential if you no longer need it).

To spend again, paste a fresh key; if you revoked the delegation, create a new one — see [Using the Catalog from a harness](/products/catalog/from-a-harness).
