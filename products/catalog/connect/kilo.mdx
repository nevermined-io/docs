Kilo Code can browse the [Nevermined Catalog](/products/catalog/overview) and pay for services as it works, without you handing over an API key. You add one server, approve a single spending cap, and Kilo Code does the rest. This is the per-host walkthrough; for the concept and the other assistants, see [Using the Catalog from your web assistant](/products/catalog/from-your-web-assistant).

## Before you connect

<Steps>
  <Step title="A Nevermined account">
    Free, at [nevermined.app](https://nevermined.app). You never share an API key with Kilo Code — the consent cap *is* the credential.
  </Step>
  <Step title="A funded wallet">
    A paid call draws on a **spending cap** you approve during connect — a [commerce grant](/mcp/catalog-mcp/overview#auth-&-transport): a capped, revocable budget funded from your own wallet, not a key. Fund that wallet first with the asset the service settles in — see [Fund your wallet](/products/catalog/router/quickstart#3-fund-your-wallet). You approve the cap itself in [Approve the spending cap](#approve-the-spending-cap).
  </Step>
</Steps>

<Note>
Start on **sandbox**, where you use testnet funds and nothing costs real money, before you point Kilo Code at **live**.
</Note>

## Add the Catalog to Kilo Code

<Steps>
  <Step title="Add the MCP server">
    In Kilo Code open **Settings → MCP → Add Server**, choose **Remote (HTTP)**, and paste the URL for your environment:

    | Environment | Server URL |
    | --- | --- |
    | **Sandbox** — the right place for a first run | `https://mcp.sandbox.nevermined.app/mcp` |
    | **Live** — real merchants, real money | `https://mcp.live.nevermined.app/mcp` |

    Leave the headers / client id empty — in the VS Code extension Kilo runs the OAuth (PKCE) flow for you, identifying itself with its own client metadata document, so there is nothing to register. In the Kilo **CLI**, add it instead to your Kilo config (`~/.config/kilo/kilo.json`, or `./kilo.json` / `.kilo/kilo.json` for a project) as a `type: "remote"` entry with the `url`, then run `kilo mcp auth` to authenticate.
  </Step>
  <Step title="Authorize">
    Kilo opens a browser to Nevermined's consent page on your first **paid** call — see [Approve the spending cap](#approve-the-spending-cap). Browsing and free tools need no sign-in.
    {/* TODO (D4 per-host check — argocd#785 trust entries): "first paid call" assumes this host retries a mid-session 401 like Claude does.   </Step>
</Steps>

## Approve the spending cap

Kilo Code opens Nevermined's consent page on your first **paid** call. Discovery and free tools need no credential. It is the one place a human is required.

<Steps>
  <Step title="Check who and where">
    The page shows the **Sandbox / Live** badge and **who is asking**. On **live**, the cap is real money.
  </Step>
  <Step title="Set the cap and validity">
    Set the **spending cap** (USDC or EURC) and how long the grant is **valid for**, then **Grant access**.
  </Step>
</Steps>

That approval is a **commerce grant**: it spends only from the budget you just approved, only through the [Router](/products/catalog/router/overview), and you can revoke it any time. Nevermined's routing fee comes out of the same cap, and the grant can also read your payment history and wallet balance — [the cap bounds what it can spend, not what it can see](/mcp/catalog-mcp/overview#what-the-consent-page-asks).

## Make your first paid call

Ask for something only live data can answer, and name the connector so Kilo Code reaches for it rather than answering from memory.

<Steps>
  <Step title="Browse for free">
    Ask *"list the Nevermined catalog categories"* — a free tool call, no sign-in.
  </Step>
  <Step title="Ask it to buy">
    *"Buy the service with slug `<slug>` through the Nevermined connector and show me the response."* The paid call draws on the cap you approved and returns the merchant's response.
  </Step>
</Steps>

<Tip>
If Kilo Code answers without paying, it answered from its own knowledge — name the connector and ask for live data. More on phrasing: [Catalog MCP tips](/mcp/catalog-mcp/overview#connect-from-your-assistant).
</Tip>

## Disconnect

- **Revoke the budget (Nevermined side).** Open [Connections](https://nevermined.app/connections) and disconnect Kilo Code. The credential stops working on its next call; discovery still works.
- **Remove the connector (Kilo Code side).** Remove the server from Kilo's MCP settings (**Settings → MCP**), or delete its entry from the config file.

To spend again — after you disconnect, or after a cap is used up — re-run the connect step and approve a **new** cap. A budget is never widened or extended in place.
