The **Catalog MCP** (also called the Commerce MCP) is a hosted [MCP](https://modelcontextprotocol.io) server that drops the Nevermined Catalog and Router straight into the tools an AI assistant already has. Point any MCP host — Claude, ChatGPT, Cursor, a generic MCP client — at it, and your agent can **discover** paid services in the [Nevermined Catalog](/products/catalog/overview) and **pay** for them through the [Router](/products/catalog/router/overview), all from a budget you cap. No code, no per-vendor signup: the server holds no funds and stores no state, and every payment draws on the caller's own spend-capped Delegation.

<Note>
This is the **buyer** side, packaged as MCP tools. If you instead want to put a paywall on *your own* MCP server so its tools get paid, that's the seller side — see [MCP Integration](/integrations/mcp). The [Docs MCP](/mcp/docs-mcp/overview) is a third, unrelated server that streams this documentation into your IDE.
</Note>

A **Delegation** is a payment method plus a spend mandate: an amount, an expiry and a number of purchases. The MCP spends only inside it.

## Install

| Environment | Server URL |
| --- | --- |
| **Live** | `https://mcp.live.nevermined.app/mcp` |
| **Sandbox** | `https://mcp.sandbox.nevermined.app/mcp` |

Discovery needs no key. Paying needs a Nevermined API key ([get one](/agents-guide/get-api-key)) and a funded Delegation ([enroll a card](/agents-guide/enroll-card)). For a first run, use the sandbox URL with a sandbox API key (`sandbox:...`): a key works only in the environment it was issued for.

<Tabs>
  <Tab title="Claude Code">
    Set `NVM_API_KEY` in your shell first: the command expands it once, into the stored server config.

    ```bash
    claude mcp add --transport http nevermined-catalog https://mcp.live.nevermined.app/mcp \
      --header "Authorization: Bearer ${NVM_API_KEY}"
    ```
  </Tab>
  <Tab title="Codex">
    ```toml
    # Add to ~/.codex/config.toml
    [mcp_servers.nevermined-catalog]
    url = "https://mcp.live.nevermined.app/mcp"
    bearer_token_env_var = "NVM_API_KEY"
    ```

    Codex reads `NVM_API_KEY` from its environment when it starts, so restart Codex after setting it.
  </Tab>
  <Tab title="Cursor">
    Add this entry under `"mcpServers"` in `~/.cursor/mcp.json`, next to any servers already there:

    ```json
    "nevermined-catalog": {
      "url": "https://mcp.live.nevermined.app/mcp",
      "type": "http",
      "headers": { "Authorization": "Bearer YOUR_NEVERMINED_API_KEY" }
    }
    ```

    Or merge it from the shell with `jq`, which keeps your existing servers and leaves the file untouched if it cannot parse it:

    ```bash
    mkdir -p ~/.cursor && f=~/.cursor/mcp.json && { [ -s "$f" ] || echo '{}' > "$f"; } && \
      jq --arg k "$NVM_API_KEY" '.mcpServers["nevermined-catalog"] = {url: "https://mcp.live.nevermined.app/mcp", type: "http", headers: {Authorization: ("Bearer " + $k)}}' \
      "$f" > "$f.tmp" && mv "$f.tmp" "$f"
    ```
  </Tab>
  <Tab title="Continue">
    ```json
    // Add to ~/.continue/config.json
    {
      "mcpServers": [
        {
          "name": "nevermined-catalog",
          "url": "https://mcp.live.nevermined.app/mcp",
          "transport": "http",
          "requestOptions": {
            "headers": { "Authorization": "Bearer YOUR_NEVERMINED_API_KEY" }
          }
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Claude Desktop">
    ```json
    // Add to ~/Library/Application Support/Claude/claude_desktop_config.json
    {
      "mcpServers": {
        "nevermined-catalog": {
          "url": "https://mcp.live.nevermined.app/mcp",
          "type": "http",
          "headers": { "Authorization": "Bearer YOUR_NEVERMINED_API_KEY" }
        }
      }
    }
    ```
  </Tab>
</Tabs>

Then restart your host to activate the connection. A **stdio-only** host can bridge with [`mcp-remote`](https://www.npmjs.com/package/mcp-remote).

<Warning>
These point at **live**, where `pay_service` moves real funds. Rehearse on sandbox first: use `https://mcp.sandbox.nevermined.app/mcp` with a **sandbox** API key (`sandbox:...`), because a key works only in the environment it was issued for. Then switch to live with a small Delegation cap and the cheapest sub-cent service.
</Warning>

**Hosts that need no API key.** Claude (claude.ai), ChatGPT, Claude Code, LangSmith Fleet, and Cursor through the Nevermined plugin in the Cursor Marketplace run OAuth for you: connect by URL and approve a spending cap once. See [Connect from your assistant](/mcp/catalog-mcp/overview#connect-from-your-assistant). The API-key setup above is for every other host, and for Claude Code or Cursor when you prefer a key.

The [full guide](/mcp/catalog-mcp/overview) also covers the quickstart and every tool.

## How it fits: discover, then pay

<CardGroup cols={2}>
  <Card title="Discover" icon="magnifying-glass">
    [`list_categories`](/mcp/catalog-mcp/list-categories), [`search_services`](/mcp/catalog-mcp/search-services), and [`get_service`](/mcp/catalog-mcp/get-service) read the [Catalog](/products/catalog/discover) — public, no key. Your agent finds a service and reads its protocol, endpoint, and price.
  </Card>
  <Card title="Pay" icon="route">
    [`pay_service`](/mcp/catalog-mcp/pay-service) hands the call to the [Router](/products/catalog/router/overview), which reads the merchant's `402`, pays it from your Delegation, enforces the cap, and relays the vendor's response. [`route_by_intent`](/mcp/catalog-mcp/route-by-intent) does both steps in one call.
  </Card>
</CardGroup>

Your agent never holds a private key, never learns a payment protocol, and never needs an account with the service it just paid. The Router, not the agent, speaks each rail — see [How the Router works](/products/catalog/router/how-it-works).

## Not this MCP

Nevermined ships three MCP servers. Make sure you want this one:

| MCP | Side | What it's for |
| --- | --- | --- |
| **Catalog MCP** (this page) | Buyer | Your agent discovers & pays for Catalog services. You provide just an API key and a funded budget. |
| [MCP Integration](/integrations/mcp) | Seller | Put a paywall on *your own* MCP server with the Payments Library (`withPaywall`), so your tools get paid. |
| [Docs MCP](/mcp/docs-mcp/overview) | — | Streams the Nevermined **documentation** into your IDE so an assistant can vibe-code an integration. It sells nothing. |
